# **App Name**: Community-Websites

## Core Features:

- Subscription Management: Allow users to view and manage their active ad subscriptions purchased on Community-Websites.com.
- Ad Campaign Pricing: Admins can set prices for ad campaigns on various community websites.
- Discount Offers: Enable admins to create and manage discount offers for ad subscriptions to incentivize new and returning customers.
- Firebase Authentication: Secure the platform using Firebase Authentication with Google Account login to ensure only authorized personnel can access the admin panel.
- Ads are sold: Ads are sold on a monthly, quarterly, or yearly bases at a set monthly fee.

## Style Guidelines:

- Primary color: blue (#244272) to reflect trust and modernity, aligning with the requested theme.
- Background color: Light blue (#E8F0FE) to create a soft, professional backdrop that complements the deep blue.
- Accent color: Electric purple (#285295) for highlighting calls to action and important information.
- Body and headline font: 'Inter' for a modern and clean aesthetic across all text elements.
- Use minimalist, line-style icons to maintain a clean and modern user interface.
- Employ a grid-based layout to ensure a structured and responsive design.
- Incorporate subtle animations for a dynamic and engaging user experience, particularly on interactions like button hovers and form submissions.
